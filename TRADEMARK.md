# Saturn — names and marks

**Saturn**, the Saturn wordmark and logo, and the look of the app are the identity
of this project. That identity belongs to **Actizant**, the startup behind Saturn
(Shreshtha Das and Soumwadeep Guha). This page spells out where you can stand with
it.

## The short version

Saturn's code is open source under the Apache License 2.0, so you are free to run,
study, modify and even redistribute it. What that license never grants is permission
to take the Saturn name or face and put them on something else, or strip them off and
call the result yours. The code is free; the identity stays Actizant's.

## Perfectly fine

- Calling the project **Saturn** and talking about what it does.
- Showing the name or logo in your own writing, reviews, demos and discussions.
- Describing a fork, integration or compatible tool accurately — as long as you do
  not imply *we* made or blessed it.
- Building something new on top of Saturn for yourself, under the license terms.

## Not without a written yes from Actizant

- Renaming Saturn and releasing it as your own assistant.
- Shipping a build that removes or hides Saturn identity and presents itself as an
  original product.
- Using the Saturn name, logo or visual style as your own branding, or in a way that
  reads as endorsement, sponsorship or partnership.
- Any commercial use of the name or marks.

None of this limits the code you add yourself; it protects the brand so the project
stays recognisably itself wherever it runs.

## Want to use the marks properly?

Ask. Reach the maintainers through https://github.com/Actizant/Saturn and describe
what you have in mind — permission is available where the intent is honest.
